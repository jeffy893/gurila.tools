# Legacy Code & Utilities

Historical implementations and utility scripts that demonstrate foundational concepts.

## Contents

- **Posterity_Android_App** - Mobile application for demographic modeling
- **calendar** - Calendar processing utilities
- **json-gen.py** - JSON generation scripts
- **moraleAgentModel.py** - Agent-based morale modeling

## Purpose

These legacy components showcase:
- Mathematical modeling capabilities (Lanchester Laws, demographic models)
- Mobile development experience
- Data processing and generation utilities
- Agent-based simulation foundations

## Relationship to Current Projects

Legacy code provides proof-of-concept implementations that inform the design of the three flagship projects, particularly the simulation and modeling components of the Integrated Analytics Suite.
