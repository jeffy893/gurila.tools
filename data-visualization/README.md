# Data Visualization Portfolio

Tableau workbooks and datasets demonstrating analytical capabilities across diverse domains.

## Categories

- **Books** - Amazon bestsellers analysis
- **Chocolate** - Cacao flavor ratings and origins
- **Games** - Video game sales trends
- **Healthcare** - Diabetes prediction models
- **Movies** - IMDB top films analysis
- **Music** - European music tourism patterns
- **Sports** - Baseball, hockey, Olympics statistics
- **Students** - Lifestyle and success correlations

## Capabilities Demonstrated

- Multi-domain data integration
- Interactive dashboard creation
- Statistical modeling and visualization
- Pattern recognition across datasets
- Automated report generation

These examples support the **Integrated Analytics & Simulation Suite** project by showcasing proven analytical frameworks and visualization techniques.
